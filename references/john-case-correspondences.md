# John Case Correspondences

Use this file for John Case's geomancy material. Case often writes an astrological condition instead of a figure name. Treat that astrological condition as Case's figure-name substitute and as his planetary/zodiacal correspondence system, distinct from Agrippa and other systems.

Normalize figure names to the user's standard Chinese names. If the DOCX uses a different translation, silently correct it in ordinary explanations and mention the correction only if useful.

## Standard Replacement Rule

When reading or explaining John Case passages:

- Replace astrological condition phrases with the standard Chinese figure name.
- If needed, show `中文名 / English name / Case condition`.
- Do not leave terms like "大胜", "小胜", "大众", "少女", "少年", "监狱", "损失", or "龙头" as the primary names. Use 大吉、小吉、群众、女人、男人、限制、失去、龙首.

## 顺行 and 逆行

Case explains 顺行 and 逆行 as interpretive states:

- **顺行**: swift, smooth, effective in business or transactions.
- **逆行**: decline, wasting, weakening, or consumption of wealth/power.

Do not assume this is identical to ordinary astronomical retrogradation. In Case's text, 顺行/逆行 is part of his symbolic condition-name system.

## Case Question Templates

Use these templates only when the user asks for John Case's approach or asks about material from the Case DOCX.

- Health and illness: 1宫 = 病人/问卜者；6宫 = 疾病；7宫 = 医生；10宫 = 药物；11宫可看恢复。1宫进入6、8、4宫且为凶卦时，病势危险；第8宫受扰或进入角宫也加强死亡判断.
- Love and marriage: 1宫和7宫代表双方。两者有拱、六合、合或吉伴时利婚恋；刑、冲、凶卦则难成。固定卦主稳定，变动卦主易变，双体卦主多次关系或不单一。
- Lost or stolen goods: 2宫看物品，7宫看盗贼或对方，4宫看藏匿处和结局。7卦与1卦同宫或有吉相位，物品较易归还；刑冲或无相位则不愿归还。方位可按角宫判断：10宫南，7宫西，4宫北，1宫东；再用元素修正环境。
- Travel and voyage: 9宫主远行。利航行与速度的卦包括获得、龙首、大吉、小吉、喜悦；利水路的卦包括群众、女人、喜悦、白色、获得。
- Weather and public change: 10宫为主要观察点，同时看1宫、10宫、11宫。火主晴朗，风主风与晴，水主湿气和雨，土主寒冷干燥。水质卦在关键宫位常主降雨；悲伤在自然判断中也可主雨。
- Friends and support: 11宫看朋友、帮助与愿望。1宫和11宫吉相、吉伴、吉卦，表示朋友可靠且愿望有助力；龙尾在11宫可主朋友不忠。
- Imprisonment and release: 12宫主监禁。1宫强且吉，较易脱困；1卦进入3宫或9宫，可主较快释放；1卦进入4、8、12宫，或1宫与12宫刑冲，则释放困难。道路在12宫可主迅速释放。

## Notes on Inconsistencies

- In one early line, the table appears to give 悲伤 as `木星逆行于双子座`, but the later name list gives `土星逆行于双子座：名称，悲伤`. Use `土星逆行于双子座` as the standard Case correspondence unless the user asks to inspect variants.
- The text sometimes writes 小吉 as `太阳逆行于天秤座（或水星）`. Use `太阳逆行于天秤座` as the standard entry and mention the parenthetical only in detailed source comparison.
- The document sometimes uses nonstandard Chinese names. Always normalize to the user's terms:
  - 大胜 -> 大吉
  - 小胜 -> 小吉
  - 大众 -> 群众
  - 少女 -> 女人
  - 少年 -> 男人
  - 监狱 -> 限制
  - 损失 -> 失去
  - 龙头 -> 龙首

## How to Explain to Users

When a user asks about a Case passage, answer like this:

1. Identify the astrological condition phrase.
2. Replace it with the user's standard figure name.
3. Give the English name and point pattern.
4. State that this is John Case's correspondence system, not Agrippa's.
5. Explain the passage using the normalized figure name.

Example:

`太阳顺行于狮子座` = 大吉 / Fortuna Maior / 2211 in John Case's system. Case is not merely saying "the Sun in Leo" as ordinary astrology; he is using that condition as the name and correspondence of 大吉.
