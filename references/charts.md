# Charts

## Figure Generation

Western geomancy commonly begins with four mother figures. Each figure has four rows, often read top-to-bottom. Random marks, points, dice, numbers, cards, or software may be used if they produce odd/even parity for each row.

When illustrating a specific figure, give the numeric pattern first and then a top-to-bottom point diagram if helpful. Do not include point diagrams for every figure unless the user is learning figure structure.

Core parity rule:

- Odd count = one point.
- Even count = two points.
- Combining rows uses parity: same parity gives two points; different parity gives one point.

## Figure Addition

Combine figures row by row:

| Row A | Row B | Result |
| --- | --- | --- |
| 1 | 1 | 2 |
| 2 | 2 | 2 |
| 1 | 2 | 1 |
| 2 | 1 | 1 |

This is parity addition. Same parity resolves to even/two points; mixed parity resolves to odd/one point.

## Shield Chart

The shield chart is the core computational layout:

- 1-4: 母卦.
- 5-8: 女儿卦, made from rows of the 母卦.
- 9-12: 侄女卦, made by combining pairs.
- 13: 右证人.
- 14: 左证人.
- 15: 法官.
- 16: 调解者 in traditions that use a sixteenth figure.

Use the shield chart for the symbolic logic of the question, especially 右证人, 左证人, 法官, 调解者, and 点之路.

## Shield Construction Steps

1. Generate four 母卦.
2. Make 女儿卦1 from the Fire/top rows of 母卦1-4.
3. Make 女儿卦2 from the Air/second rows of 母卦1-4.
4. Make 女儿卦3 from the Water/third rows of 母卦1-4.
5. Make 女儿卦4 from the Earth/bottom rows of 母卦1-4.
6. Add 母卦1 + 母卦2 = 侄女卦1.
7. Add 母卦3 + 母卦4 = 侄女卦2.
8. Add 女儿卦1 + 女儿卦2 = 侄女卦3.
9. Add 女儿卦3 + 女儿卦4 = 侄女卦4.
10. Add 侄女卦1 + 侄女卦2 = 右证人.
11. Add 侄女卦3 + 侄女卦4 = 左证人.
12. Add 右证人 + 左证人 = 法官.
13. Optionally add 法官 + 母卦1 = 调解者.

## House Chart

The house chart places figures into astrological houses. Use it for topics where houses matter: self, money, siblings, home, children, illness, partnership, death, travel, office, friends, enemies, and so on.

Common workflow:

1. Construct the shield chart.
2. Transfer or derive figures into houses according to the method being used.
3. Identify significator houses for querent, quesited, and topic.
4. Assess 精准相位, aspects, and condition.

## House Topics

Use the usual twelve-house logic unless a tradition states otherwise:

| House | Topic |
| --- | --- |
| 1 | Querent, body, immediate condition |
| 2 | Money, movable possessions, livelihood |
| 3 | Siblings, neighbors, messages, short trips |
| 4 | Home, land, parents, endings, buried things |
| 5 | Children, pleasure, creativity, games |
| 6 | Illness, servants/employees, small animals, labor |
| 7 | Partner, opponent, buyer/seller, open enemy |
| 8 | Death, fear, other people's money, loss |
| 9 | Long travel, religion, dreams, higher learning |
| 10 | Career, authority, reputation, judgment |
| 11 | Friends, helpers, hopes, patrons |
| 12 | Hidden enemies, confinement, self-undoing, large animals |

## Choosing Significators

Default assignments:

- Querent: House 1.
- Other person in a relationship/contract/conflict: House 7.
- Money or object owned by querent: House 2.
- Lost object: House 2 unless the object clearly belongs to another house.
- Job/career: House 10.
- Home/land: House 4.
- Illness: House 6 for illness, House 1 for the body/person.
- Children/pregnancy: House 5, with careful non-medical framing.

For third-party questions, turn houses only when the question is genuinely about another person from their perspective. Otherwise, preserve the querent's viewpoint.

## Cautions

- Do not mix transfer systems without naming the system.
- Do not assume Arabic-course Taskin ordering applies here.
- If a user gives a chart from another school, ask or infer the construction method before interpreting.
- Do not read every house exhaustively. Start with the question, significators, and only then supporting houses.
