# Figure Meaning Layers

Use this file whenever explaining the meaning of a figure. Keep the three layers distinct:

1. **现代卦义**: modern technical reading from contemporary geomancy practice, figure shape, element, planetary/zodiacal logic, and modern synthesis.
2. **古典卦义**: classical house-based meanings from the user's DOCX source, especially Agrippa and Christopher Cattan; mention that classical meanings often depend strongly on house and topic.
3. **中世纪社会原型（由靓靓aloys原创）**: the user's medieval social-archetype model. Always use this label for the archetype layer.

Do not blend these layers into one undifferentiated meaning. If the layers disagree, say so and explain the tension.

## Method Notes From the User's Research

The user has written two source essays arguing that European geomantic figure meanings became heavily filtered through astrology. Preserve this as a methodological caution, not as a rejection of all astrological correspondences.

When explaining a figure:

- Do not reduce the figure meaning to its planet or zodiac sign.
- Treat astrological correspondences as one interpretive layer, especially strong in medieval and Renaissance European material.
- When a planet/zodiac correspondence conflicts with older figure meanings or the user's medieval social-archetype model, explain the conflict instead of forcing harmony.
- The user's preferred reconstruction gives priority to older figure meanings and social prototypes, then compares later astrological overlays.

Important distinction:

- Cattan's correspondence logic often follows the figure's meaning first, then chooses an astrological condition that expresses that meaning.
- Agrippa's system is more schematic: it distributes planets and zodiac signs across the figures in a way that later became influential but can sometimes pull interpretation away from older figure meanings.

Example teaching pattern:

1. Start with the figure's technical shape and core meaning.
2. Add classical house-based meanings.
3. Add the user's medieval social archetype.
4. Only then add astrological correspondence, noting whether it clarifies or distorts the figure.

## Figure Notes

### 大吉 / Fortuna Maior

- **现代卦义**: 表示当前可能有困难，但最终走向成功；成功依赖勇气、基础、品格、长期积累和内在力量。利长期主义、成长、稳固推进；不利急速求成或完全依赖别人。
- **古典卦义**: 几乎各方面正面，象征尊贵、和平、强力保护、忠诚、富贵和良好品格。遇敌人也常表示对方强大但品行尚可，诉讼可和平解决。
- **中世纪社会原型（由靓靓aloys原创）**: 最高统治者，如国王、皇帝、教皇。社会秩序围绕其意志运行，所以卦义呈现"强大的向好"。

### 小吉 / Fortuna Minor

- **现代卦义**: 快、动、不稳定，需要外界帮助才能成功；有短期优势，但不一定持久。
- **古典卦义**: 与战争、勇气、争斗、胜利、愤怒、挥霍和关系不和有关；在争斗、军事、竞争中可吉，在和平关系中易生纠缠。
- **中世纪社会原型（由靓靓aloys原创）**: 通过军功获得地位和领土的领主，能打、会扩张，但脾气和人际问题也多。

### 喜悦 / Laetitia

- **现代卦义**: 欢快、目标感、快速完成、三分钟热度；利快乐、娱乐、短期完成，不利长期稳定和深度研究。
- **古典卦义**: 核心是玩乐与法律；表示教养、名望、公正、朋友与爱人忠诚、疾病康复、失物寻回、贵人相助，但也可能承诺多而兑现少。
- **中世纪社会原型（由靓靓aloys原创）**: 家里有关系、生活轻松、成年后被安排进体制/法律系统的富家子弟；也对应法官、法律人士、公正与荣耀。

### 悲伤 / Tristitia

- **现代卦义**: 像深坑，表示持续低迷、失败感、困境纠缠、沉重且不易解决的状态。
- **古典卦义**: 贫穷、疾病、痛苦、背叛、人心险恶；少数情况下利农业、建筑、防御、保密、艰苦劳动。
- **中世纪社会原型（由靓靓aloys原创）**: 农奴、底层劳作者、困苦环境中的人。其有利事项往往来自底层劳动者的职责范围。

### 红色 / Rubeus

- **现代卦义**: 冲动、放纵、暴力、失控、突发破坏。多数事项不利，只在冲突、暴力、破坏性事务中可能"顺势"。
- **古典卦义**: 完全凶卦，表示欺骗、背叛、战争、流血、争斗、灾难和人为难以控制的破坏。
- **中世纪社会原型（由靓靓aloys原创）**: 铁匠。不是因为铁匠低贱，而是火、金属、危险工艺、破坏性力量构成了红色的社会图像。

### 白色 / Albus

- **现代卦义**: 思考、灵感、内在智慧、冷静判断；利学习、思考、沟通、和平，不利快速行动、短期爆发和强依赖外援。
- **古典卦义**: 智慧、技艺、口才、商业、社交、贵人、婚姻美满；也可能指疾病缠身、难以康复。对身份卑微者更有利，对高位者未必有利。
- **中世纪社会原型（由靓靓aloys原创）**: 掌握技艺的人，如首饰工匠、艺人、杂耍者、靠口才或技术得到赏识的人。

### 男人 / Puer

- **现代卦义**: 行动、冲动、身体性冲突、热情、勇气；利快速行动、战争、竞争、需要经验和胆量的事，不利稳定、谋划、长期和平关系。
- **古典卦义**: 军功、掠夺、争斗、荣誉、受人敬畏、旅途危险、婚姻不幸、不忠、性欲、恋爱短期有利、疾病康复。
- **中世纪社会原型（由靓靓aloys原创）**: 骑士。中世纪骑士多依附上层权力，以武力执行意志，也可能借军功跨越阶级。

### 女人 / Puella

- **现代卦义**: 愉快、和谐、协调、平衡、情感包容；利和平、关系调和、短期美好，不利快速攻击、强行动力和长期硬撑。
- **古典卦义**: 娱乐、艺术、爱情、子女、和平、财富与继承；轻病可康复，不利战争和远行。
- **中世纪社会原型（由靓靓aloys原创）**: 中世纪女性、情人、寡妇、娱乐与舞乐服务者等"快乐提供者"。其和平与愉悦来自社会角色，而不是抽象的温柔标签。

### 获得 / Acquisitio

- **现代卦义**: 获得、吸收、积累、扩张；不论好坏都"照单全收"，因此在疾病、债务、麻烦中也可能表示问题增加。
- **古典卦义**: 财富、资产丰足、受尊敬、贵人扶持、诉讼有利、学习和升迁有利；疾病可能拖重，囚犯释放不利。
- **中世纪社会原型（由靓靓aloys原创）**: 钱。可理解为商人、财政署、有官方背景的富人；富多于贵，核心是资源进入与资产累积。

### 失去 / Amissio

- **现代卦义**: 失去、消耗、放手、结束；利结束、消失、消耗、摆脱，不利获得、开始、稳定和长期维持。感情上常是执念和不愿放手，不等于复合有利。
- **古典卦义**: 钱财失去、贫困、不忠、流产、无法继承、死亡、债务偿还、小人作祟；在疾病问题上有时表示病被"失去"而康复。
- **中世纪社会原型（由靓靓aloys原创）**: 盗贼/窃匪语境中被夺走的一方。和获得相反，不是赢家获得，而是当事人承受损失。

### 限制 / Carcer

- **现代卦义**: 切断外界连接、无进展、延迟、约束、边界、框架；利安全、稳定、不变和防御，不利变动、快速、移动。
- **古典卦义**: 监禁、受刑、贫困、劳役、无法释放；在建城、防御、违法事务、艰苦劳动等领域可有利。
- **中世纪社会原型（由靓靓aloys原创）**: 囚犯、受刑者、被框架困住的人。它的稳定来自被封闭，而不是顺利安稳。

### 结合 / Coniunctio

- **现代卦义**: 信息汇总、交汇、连接、计划、沟通、慢慢行动、思考学习；易受周围卦影响，遇吉则吉，遇凶则凶。
- **古典卦义**: 智慧、学习、技艺、计划、勤奋带来的收益；财富不如获得巨大，疾病和死亡问题中可表示漫长痛苦。
- **中世纪社会原型（由靓靓aloys原创）**: 哲学家、先知、作家，文化/知识工作者。重点是把不同信息、思想、人事连接起来。

### 龙首 / Caput Draconis

- **现代卦义**: 新阶段的开始、进入、向上、向前；常是不由个人意志完全控制的开启。利开始项目、关系、新阶段；不利结束和毁坏。
- **古典卦义**: 除战争、违法、道德败坏、疾病等负面事项外，多数问题皆吉；利健康、和平、财富、农业、建筑和贵人支持。
- **中世纪社会原型（由靓靓aloys原创）**: 没有明确职业原型，更像正面社会价值本身：积极、正向、岁月静好。

### 龙尾 / Cauda Draconis

- **现代卦义**: 结束、走出、主动切断、主观终止；利结束项目、离开关系、停止不想继续的事。疾病上现代与古典有张力，应谨慎。
- **古典卦义**: 凶性强，破坏、暴力、背叛、边缘、疾病加重；只在战争、破坏、背叛等负面事项中可能有利。
- **中世纪社会原型（由靓靓aloys原创）**: 负面社会价值、边缘人、被排斥和打压的人群；与龙首构成正/负社会价值对。

### 道路 / Via

- **现代卦义**: 转变，且是彻底改变状态：吉转凶、凶转吉、稳定转移动、移动转稳定。利改动、突破、转向；不利保守、不变、稳定维持。
- **古典卦义**: 长途旅行、异地学习或经商、环境变动、分离、背叛；学习和商业中可表示拓宽思路、打开交际圈。
- **中世纪社会原型（由靓靓aloys原创）**: 旅行者。中世纪长途旅行常指跨国求学或经商，因此同时带有知识、远方、海路、变动和名望。

### 群众 / Populus

- **现代卦义**: 稳固不变、受周围影响、复制周围状态、形成共识。利稳定、不变、他人帮助；不利突破和转变。
- **古典卦义**: 人群、贸易、庆典、战争动员、集结、下属/学生/子民等群体；卦辞复杂，取决于"这群人为何聚集"。
- **中世纪社会原型（由靓靓aloys原创）**: 一群人。对君王是子民，对领导是下属，对老师是学生；核心是集合体、群体规则和被带动。

## Teaching Style

When asked "某卦是什么意思", answer in this order:

1. 中文名、英文名、点数。
2. 现代卦义，用于快速读盘。
3. 古典卦义，说明它在十二宫和具体问题中会变化。
4. 中世纪社会原型（由靓靓aloys原创），用社会角色解释为什么古典卦辞会这样写。
5. 一句使用提醒：在哪些问题上有利，哪些问题上不利。

Do not present the prototype layer as generic public tradition. It is the user's original interpretive model and should be attributed accordingly.
